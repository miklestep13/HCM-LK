# Q.HCM — прототип на Angular

Прототип HR-платформы Q.HCM («Меридиан Банк»), переносимый из однофайлового HTML-прототипа на компонентный Angular.

## Запуск

Нужен Node.js 20.19+ или 22+.

```bash
npm install
npm start
```

Откройте http://localhost:4200. Изменения в коде применяются сразу.

## Что внутри

- **Angular 21**: standalone-компоненты, signals, ленивые маршруты, hash-адреса (`#/home`).
- **Главная «Мой кабинет → Обзор»** уже на компонентах: страница собрана из блоков (профиль, развитие, награды, кошелек, отпуск, задания, обучение, карта целей, ИПР, коллеги, заявки).
- **Остальные страницы** пока открываются из старого прототипа (`public/legacy/index.html`) через мост: меню и переходы работают как раньше, адрес меняется (`#/legacy/<страница>`). По мере переноса страницы переключаются на Angular.
- **Dev-панель** — кнопка «Демо» внизу справа: переключатели демо-состояний текущей страницы (например, этап карты целей).

Структура и правила — в [AGENTS.md](AGENTS.md).

## Сборка

```bash
npm run build
```

Результат — `dist/hcm-ui/browser`: статичные файлы, можно выложить на любой хостинг или открыть через локальный сервер.
