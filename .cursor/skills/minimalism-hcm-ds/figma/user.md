## 2. Геометрия

| Вариант | Ширина по умолчанию | Аватар | Отступ аватар → текст | Высота без тегов |
|---|---|---|---|---|
| Row · S | 240 | 32 | 8 | 36 |
| Row · M | 280 | 36 | 12 | 36 |
| Row · L | 300 | 64 | 12 | 64 |
| Row · XL | 360 | 112 | 12 | 112 |
| Stack · L | 200 | 64 | 12 (вертикально) | 112 |

- Row — горизонтальный auto layout, выравнивание по центру. Текстовая колонка тянется (Fill); имя Fill с «…», тег в
  строке с именем — справа, через 8.
- Stack — вертикальный auto layout, всё по центру; подпись до двух строк.
- Аватар — фрейм размером аватара с двумя экземплярами `Avatar` друг над другом: снизу `No photo`, сверху `Photo`;
  свойство `Photo` скрывает верхний.
- Имя 14/20 SemiBold `Content/content-text`; подпись 12/16 `Base/base-500`, промежуток 0; строка тегов — padding сверху 8,
  промежуток 6.
