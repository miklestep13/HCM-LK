# KPI Card — спецификация компонента и сборка в Figma

Источник: Figma «Q.HCM-components» (`RNiVz75ZZ0mNKJxcVYNMVq`), компонент **KPI Card**, node `1:195`,
key `7eb0433068b57a341a322dbc88a97e245d125219`, сверка 30.10.2026. Размеры в px. Цвета — только переменные Q.Palette;
в CSS — токены `--q-*` (`assets/kpi-card.css`). Правила выбора — `references/kpi-card.md`.

## 1. Варианты и свойства

36 вариантов: Default, Progress, Trend × 4 статуса (Direction = Up, на вид не влияет) + Arrow subtitle, Arrow inline ×
3 направления × 4 статуса.

| Свойство Figma | Тип | По умолчанию | Подключено | CSS |
|---|---|---|---|---|
| `Type` | Variant | Default | все | структура разметки |
| `Status` | Variant | Normal | все | `.q-kpi--success` / `--warning` / `--critical` |
| `Direction` | Variant | Up | Arrow subtitle, Arrow inline | `.q-kpi__delta--up` / `--down` / `--flat` |
| `Title#282:117` | Text | `Title` | все | `.q-kpi__title` |
| `Value#282:130` | Text | `78%` | все, **кроме Trend** | `.q-kpi__value` |
| `Subtitle#282:143` | Text | `subtitle` | все, **кроме Trend** | `.q-kpi__sub` |
| `Trend value#36:69` | Text | `0%` | Arrow | текст `.q-kpi__delta` |
| `Show info#282:78` | Boolean | true | все | `.q-kpi__ib` (info-circle) |
| `Show menu#282:91` | Boolean | true | все | `.q-kpi__ib` (ellipsis-v) |

## 3. Геометрия

**Контейнер:** вертикальный auto layout, padding 12 / 16, gap 4, радиус 10, ширина Fixed (исходно 279, мин. 160,
макс. нет), высота Hug. Область содержимого — `W − 32`.

**Типографика** (в Figma тексты без стилей — привязать):

| Роль | Размер | Стиль ДС |
|---|---|---|
| Заголовок, пояснение | Regular 12/16 | `ui-description-1` |
| Значение | SemiBold 16/22 | `ui-headline-3` |
| Число изменения | SemiBold 12/16 | **в шкале нет** — ближайший `ui-button-s-xs` 600 12/20 со строкой 16 (см. §5) |

Перенос: заголовок, пояснение и значение переносятся, без многоточия и уменьшения шрифта. В Arrow inline значение и
число изменения — Hug, без переноса.

**Верхняя строка:** горизонтальная, gap 6, центр по вертикали; заголовок Fill; контейнеры иконок 20 × 20, глиф 18
(`Icons / info-circle` 1:200, `Icons / ellipsis-v` 1:202 — не заменять). Скрытая иконка отдает место заголовку.

| Type | Состав по вертикали | Исходная высота (без пояснения) |
|---|---|---|
| Default | строка · значение · пояснение | 90 (70) |
| Progress | строка · значение · пояснение · трек 6, радиус 3, заливка по доле | 100 (80) |
| Trend | строка · ряд [стек значения и пояснения (gap 4, Fill) — gap 8 — график 52 × 22], центр | 90 |
| Arrow subtitle | строка · значение · ряд [индикатор — gap 4 — пояснение (Fill)], центр | 90 (90) |
| Arrow inline | строка · ряд [значение (Hug) — gap 6 — индикатор], центр · пояснение | 90 (70) |

**Мини-график:** ломаная без сглаживания, толщина 1,39, концы Round, соединения Miter, цвет акцента; конечная точка —
круг ≈ 3,81 без обводки. Вершины в 52 × 22: (1,73; 17,93) (8,67; 16,98) (15,60; 16,63) (22,53; 17,24) (29,47; 17,33)
(36,40; 12,99) (43,33; 8,23) (50,27; 4,07). Осей, сетки, подписей и заливки нет. Геометрия статична.

**Индикатор изменения:** горизонтальный, Hug, символ → число, gap **2**, выравнивание по базовой линии числа.
- Up — треугольник-вектор 10 × 9, вершины (5; 0) (10; 9) (0; 9), нижнее ребро на базовой линии.
- Down — 10 × 9, вершины (0; 0) (10; 0) (5; 9), нижняя вершина на базовой линии.
- Unchanged — «=» вектором из двух полос 10 × 1,5 с зазором 3 (всего 10 × 6), нижняя граница на базовой линии.
  Текстовый символ шрифта не использовать.

Три разных интервала не смешивать: **2** символ → число, **4** индикатор → пояснение (Arrow subtitle),
**6** значение → индикатор (Arrow inline).

## 4. Поведение

- Скрытый элемент выпадает из auto layout, интервалы считаются между видимыми.
- Value, Trend value, Status, Direction независимы и ничего не пересчитывают. Компонент не считает изменение, не
  добавляет «%», «+», «−», единицы и не форматирует числа.
- Заливка прогресса зафиксирована на 78% и с текстом не связана. В экземпляре ее ширину изменить нельзя: у узла `Fill`
  ограничение SCALE, Figma пересчитывает ширину от варианта. Длина полосы при этом **обязана** совпадать с Value —
  обеспечивает агент (§6, шаг 4). В верстке — `--p` из того же числа.
- Интерактивность, hover, focus, disabled, loading, empty, error в компоненте не заданы. В вебе: `a.q-kpi` — ховер
  значения `--q-primary-500` и кольцо фокуса (`assets/kpi-card.css`).
- Автопереключения Type по ширине нет. Минимум 160 не гарантирует место длинному значению в Arrow inline.

## 5. Открытые вопросы

- Длина полосы Progress в экземпляре не меняется (всегда 78%); пока агент отвязывает копию. Компонент оставлен как есть
  (решение 30.10.2026).
- Число изменения SemiBold 12/16 — стиля в шкале `ui-*` нет. Нужен новый стиль (например, `ui-description-1-bold`)
  или перевод на существующий. До решения в CSS — `ui-button-s-xs` со строкой 16.
- Тексты компонента не привязаны к текстовым стилям Figma.
- Цвета пока на общих токенах Q.Palette; отдельные токены KPI и оттенки — позже, в Figma. При появлении поменять
  только таблицу §2 и `assets/kpi-card.css`.

## 6. Сборка в Figma (агент через Figma MCP)

1. Импортировать набор: `await figma.importComponentSetByKeyAsync('7eb0433068b57a341a322dbc88a97e245d125219')`
   (в самом файле компонентов — `figma.getNodeByIdAsync('1:195')`). Не рисовать карточку фигурами.
2. Экземпляр: `set.defaultVariant.createInstance()`, затем
   `inst.setProperties({ Type:'Arrow inline', Status:'Normal', Direction:'Up' })`.
3. Тексты и видимость — через свойства с ID: `inst.setProperties({ 'Title#282:117':'Оценка 360',
   'Value#282:130':'3,0', 'Trend value#36:69':'0,2', 'Subtitle#282:143':'из 5 · 14 респондентов',
   'Show menu#282:91':false })`. Перед заменой текста загрузить Open Sans Regular и SemiBold.
4. Trend: тексты менять в узлах `Value-Subtitle-Stack > Value / Subtitle` экземпляра. Progress: если Value не 78%,
   сделать полосу точной: `const d = inst.detachInstance(); const f = d.findOne(n => n.name === 'Fill');
   f.resize(f.parent.width * доля, f.height); d.name = 'KPI Card · отвязано'`. Отвязывать после того, как карточка
   встала в раскладку и получила итоговую ширину; цвета и тексты остаются на переменных и стилях.
5. Ряд — горизонтальный auto layout, gap 12, у карточек `layoutSizingHorizontal = 'FILL'`, высоты равные.
6. Цвета не переопределять: статус задается только свойством `Status`.
