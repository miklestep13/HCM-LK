# Навигация `Navigation` `.q-appbar--hcm` — шапка приложения

Читать, когда собирается каркас экрана: шапка с разделами, выпадающими списками, иконками действий и областью
пользователя. Правила общие для любого продукта на этой ДС. Особенности Q.HCM — в §8. Стили — `assets/navigation.css`.
Компоненты Figma и сборка — `references/navigation-spec.md`.

## 1. Из чего состоит

| Часть | Компонент | Что |
|---|---|---|
| Шапка | `Navigation` | h48, белая, sticky, линия снизу `--q-base-transparent-300` с прозрачностью 30 %; контейнер той же ширины, что `.q-wrap` |
| Логотип | часть `Navigation` | Знак + «Q.HCM» `ui-headline-4`; клик — главная страница продукта |
| Разделы | `Nav / Menu item`, `Level=Top` | Пункт раздела с шевроном: клик только раскрывает список |
| Выпадающий список | `Nav / Menu item`, `Level=Dropdown` / `Separator` | Страницы раздела; вложенный список — у пункта с `Submenu` |
| Иконки действий | `Button` Ghost Icon only M 36 | Поиск, уведомления, настройки (по ролям) |
| Область пользователя | часть `Navigation` | `User` Row M + шеврон 12; открывает меню пользователя |

Боковое меню (Navigation menu 280, Side-panel 300) — только админки и настройки; в продукте навигация — шапка.

## 2. Разделы и списки

- Раздел (`Level=Top`) — существительное, 1–3 слова: «Компания», «Мой кабинет», «Управление персоналом».
- Клик по разделу только раскрывает список; первая страница списка — «Обзор». Раздел страницей не является.
- Состояния раздела: Default (текст `--q-menu-text`, шеврон `--q-page-text-ui`) · Hover (фон `--q-primary-50`, текст
  `--q-primary-500`, шеврон остается `--q-page-text-ui`) · Active — раздел текущей страницы (фон `--q-primary-50`, текст и
  шеврон `--q-menu-text-active`). Открытый список — как Hover.
- Пункт списка (`Level=Dropdown`), `ui-headline-4` 14/20, h36: Default (`--q-menu-text`) · Hover и Selected — текущая
  страница (фон `--q-primary-50`, текст и шеврон `--q-menu-text-active`) · Danger — только «Выйти из аккаунта» (`--q-error-500`).
- Токен Q.Palette `--q-menu-hover` (primary 30 %) заметно темнее прототипа — в навигации не используется.
- Вложенность — один уровень: пункт с `Submenu` (шеврон вправо) открывает список справа, по верху пункта.
  Глубже не вкладывают (в прототипе вложенность одного уровня: «Обучение», «Аттестация», «Справочники»).
- Значение справа (`Show value`) — текущая настройка в меню пользователя: «Язык · Русский».
- Разделитель (`Level=Separator`) отделяет «Выйти из аккаунта» от остальных пунктов.

## 3. Иконки действий

- Только иконочные кнопки Ghost 36 (радиус 10, иконка 18 `--q-page-text-ui`), с `aria-label` и тултипом.
- Порядок: поиск → уведомления → настройки; между кнопками 0, до области пользователя 8.
- Показывают только доступные роли: настройки — у администратора; кнопку, которая не работает, не ставят.

## 4. Область пользователя

- `User` Row M (аватар 36, имя 14/20 SemiBold, должность 12/16 `--q-base-500`) + шеврон 12 `--q-page-text-ui`.
- Отступы 4 8 4 4, радиус 10; кликается вся область; Hover и открытое меню — фон `--q-primary-50`.
- Меню пользователя: «Профиль» → «Язык · Русский» → разделитель → «Выйти из аккаунта» (Danger). Выравнивание — по
  правому краю области.
- Без фото — `User` `Photo` выкл. (`pi-user` на сером).

## 5. Раскладка

- Слева: логотип → 16 → разделы (между пунктами 8). Справа: иконки действий → 8 → область пользователя.
- Выпадающий список — от низа пункта через 4, по левому краю пункта (меню пользователя — по правому краю), ширина 240,
  радиус 8, padding 4, тень dropdown, фон `--q-menu-bg`.
- Контейнер шапки — ширина `.q-wrap`: 1200 / 1240 (≥ 1280) / 1360 (≥ 1536) / 1480 (≥ 1800), поля 20.

## 6. Запреты

**Нельзя:**

1. Делать раздел ссылкой на страницу — раздел только раскрывает список.
2. Вкладывать списки глубже одного уровня.
3. Ставить справа в шапке что-то кроме иконочных кнопок 36 и области пользователя (ДС, «Каркас»).
4. Показывать раздел или кнопку, недоступные роли (например, «Управление персоналом» сотруднику).
5. Ставить `User` в шапку без области пользователя (без шеврона и меню) или аватар отдельно.
6. Красить пункт в Danger кроме «Выйти из аккаунта».
7. Делать боковое меню вместо шапки в продуктовых экранах.

## 7. Проверка

- [ ] Разделы — по роли; Active у раздела текущей страницы, Selected — у текущей страницы в списке.
- [ ] Вложенность — один уровень; разделитель перед «Выйти из аккаунта».
- [ ] Иконки — Ghost 36 с `aria-label`; только доступные роли.
- [ ] Область пользователя — `User` Row M + шеврон; меню по правому краю.
- [ ] Цвета — фон `--q-primary-50`, текст `--q-menu-text` / `--q-menu-text-active` / `--q-primary-500`, линия `--q-base-transparent-300` 30 %.

## 8. Особенности Q.HCM

- Разделы: «Компания» · «Мой кабинет» · «Управление персоналом» (только роль 2, Смирнова В. О.).
- Логотип Q.HCM открывает «Новости» (легенда); пункт меню только раскрывает список, первая страница — «Обзор».
- Вложенные списки: «Мой кабинет → Обучение» (Мое обучение, Каталог обучения).
