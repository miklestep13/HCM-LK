# Плитка `Icon` `.q-icon-tile` — объект с иконкой или изображением

Читать, когда рядом с названием объекта нужен узнаваемый знак: файл, курс, подразделение, система, тип записи, логотип.
Правила общие для любого продукта на этой ДС. Особенности Q.HCM — в §9, примеры — в §10. Стили — `assets/icon.css`.
Компонент Figma и сборка — `references/icon-spec.md`. Фото человека — не плитка, это `Avatar` (`references/avatar.md`).

## 1. Что это

Плитка той же формы и тех же размеров, что `Avatar`: скругленный квадрат. Два вида:

| `Type` | Что внутри | Когда |
|---|---|---|
| **Icon** | Иконка Q.Icons на цветном фоне | Тип объекта: документ, курс, подразделение, задача, система |
| **Image** | Любое изображение (Fill) | Логотип компании, обложка курса или мероприятия, превью |

Плитка не нажимается сама по себе: переход — по строке, карточке или названию рядом.

## 2. Когда брать

| Ситуация | Что брать |
|---|---|
| Объект, у которого есть тип или своя картинка, рядом с названием | Icon |
| Человек | `Avatar`, не Icon |
| Статус объекта | Бейдж (`badge.md`), не цвет плитки |
| Иконка-действие (редактировать, удалить) | Иконочная кнопка (`button.md`), не Icon |
| Объект в ячейке таблицы | `Table / Cell`, `Type=Icon` (Icon 32 внутри) |

## 3. Цвет (`Type=Icon`)

Пары «фон + иконка» — те же, что у бейджей Q.PALETTE, и серая.

| `Color` | Фон / иконка | Когда |
|---|---|---|
| **Default** | `badge-bg` / `page-link-active` | По умолчанию: обычный объект |
| **Grey** | `badge-grey-bg` / `badge-grey-color` | Нейтральный, неактивный, архивный объект; вспомогательные типы |
| **Info** | `badge-info-bg` / `info-700` | Справочное, информационное |
| **Success** | `badge-success-bg` / `success-700` | Завершенное, подтвержденное |
| **Warning** | `badge-warning-bg` / `warning-700` | Ждет действия |
| **Error** | `badge-danger-bg` / `error-700` | Только риск, ошибка, отказ |

- Один тип объекта — один цвет на всех экранах: если документы серые, они серые везде.
- Если цвет не несет смысла — все плитки списка Default или все Grey.
- Цвет плитки не заменяет бейдж статуса: статус пишется бейджем.

## 4. Размер

| Size | Радиус | Иконка | Где |
|---|---|---|---|
| 24 | 6 | 14 | Плотные места, мета строки |
| 32 | 8 | 18 | Таблицы и строки списков |
| 36 | 10 | 18 | Строки людей и объектов в виджетах — рядом с аватарами 36 |
| 40 | 10 | 24 | Объект в карточке или строке виджета |
| 48 | 12 | 24 | Крупный объект в шапке блока; плитки «Благодарности» и «Награды» в профиле (было 56) |
| 64 | 12 | 32 | Карточка объекта, плитка каталога |

- Размер плитки — как у аватаров в том же списке: люди и объекты в одном списке выравниваются.
- В таблице — 32.

## 5. Иконка и изображение

- Иконка — только Q.Icons (PrimeIcons, `pi-*`), одна на тип объекта; цвет — из пары `Color`, не произвольный.
- Изображение — заливка Fill по центру, без полей и рамки; фото людей в `Type=Image` не ставят.
- Буквы, цифры и эмодзи в плитку не ставят.

## 6. Рядом с плиткой

- Название — справа через 8, 14/20 SemiBold; подпись под ним 12/16 `base-500` вплотную.
- Плитка и текст — по центру строки.

## 7. Запреты

**Нельзя:**

1. Ставить в плитку фото человека — для людей есть `Avatar`.
2. Делать плитку кругом или брать размер вне шкалы 24 · 32 · 36 · 40 · 48 · 64.
3. Красить иконку и фон вне пар `Color` или смешивать пары (фон одной, иконка другой).
4. Показывать статус цветом плитки вместо бейджа; красить в Error что-то кроме риска, ошибки, отказа.
5. Давать одному типу объекта разные цвета или иконки на разных экранах.
6. Ставить в плитку буквы, цифры, эмодзи.
7. Делать плитку кнопкой-действием.

## 8. Проверка

- [ ] Объект, а не человек; Type по §1.
- [ ] Цвет по §3, один цвет на тип объекта; статус — бейджем.
- [ ] Размер по §4, как у соседних аватаров; в таблице 32.
- [ ] Иконка из Q.Icons; цвет иконки и фона — из одной пары.
- [ ] Название справа через 8, подпись вплотную.

## 9. Особенности Q.HCM

- В таблицах «Моего кабинета» и «Управления персоналом» — `Table / Cell`, `Type=Icon` для объектов с типом
  (документы, курсы, подразделения).
- Обложки курсов и мероприятий в карточках каталога — это шапка-превью `.q-phead` и карточки (`SKILL.md`), не плитка 64;
  плитка `Type=Image` — для маленьких превью рядом с названием.
- Тексты рядом — из `hcm-demo-legend`, без стоп-листа.

## 10. Примеры

| Где · роль | Плитка |
|---|---|
| Таблица задач ИПР · Павел Иванов | `Type=Icon`: Icon 32 Default `pi-file` + «Памятка по пакету документов» (допущение: иконка) |
| Подразделения в оргструктуре · Смирнова | Icon 32 Grey `pi-users` + «HR-дирекция» (допущение: иконка) |
| Плитка логотипа | `Type=Image`: логотип АО «Меридиан Банк» 40 |
