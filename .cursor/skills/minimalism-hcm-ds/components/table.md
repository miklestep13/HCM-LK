# Таблица `.q-table` — когда брать, какие ячейки, как собрать

Читать, когда на экране список однотипных записей, которые сравнивают по столбцам: сотрудники, планы, задачи,
компетенции, заявки. Правила общие для любого продукта на этой ДС. Особенности Q.HCM — в §10, примеры из прототипа —
в §11. Стили — `assets/table.css`. Компоненты Figma `Table / Header` и `Table / Cell`, их свойства и сборка —
`references/table-spec.md`.

## 1. Что это

Таблица — строки записей и столбцы атрибутов. Собирается из двух компонентов:

| Компонент | Что это | Выбор вида |
|---|---|---|
| `Table / Header` | Заголовок столбца | `Type`: Text, Checkbox, Empty · `Sort` · `Align` |
| `Table / Cell` | Ячейка тела, строка группы, пустая строка | `Type` (18 видов, §3) · `Variant` · `Align` |

Отдельного компонента строки нет: строка — горизонтальный auto layout из ячеек, таблица — вертикальный из строк.
Подсветка строки, линия снизу и отступы — свойства ячейки, поэтому любой набор столбцов собирается из тех же двух
компонентов.

## 2. Когда брать

| Ситуация | Что брать |
|---|---|
| Записи сравнивают по 3+ атрибутам, их можно сортировать | Таблица |
| Записей много, нужен поиск и фильтры | Таблица в виджете `.q-widget--full` с `.q-ftbar` сверху (паттерн «Список раздела») |
| 1–2 атрибута, узкий виджет, главное — название | Строка списка `.q-item` |
| Записи с обложкой, описанием, действием в карточке | Сетка карточек |
| Пары «метка — значение» одного объекта | `.q-dl`, не таблица |
| Одно число-итог | KPI-карточка |

## 3. Какую ячейку выбрать

| Данные в столбце | `Type` · `Variant` | Выравнивание |
|---|---|---|
| Название записи (первый столбец, ведет на страницу) | Text · Strong, с `Subtitle` при второй строке | Слева |
| Обычный текст, атрибут | Text · Default | Слева |
| Второстепенный текст, «—» вместо пустого значения | Text · Secondary | Слева |
| Ссылка внутри ячейки, код записи | Text · Link | Слева |
| Отрицательное значение, риск (не дата) | Text · Danger | Слева |
| Положительное значение | Text · Positive | Слева |
| Дата, срок | Date · Default | Слева |
| Просроченный срок | Date · Overdue, подпись «10 дней назад» | Слева |
| Сумма, количество, процент без полосы | Number · Default / Positive / Negative | Справа |
| Сотрудник | Person (Avatar 32 + имя + должность) | Слева |
| Объект с иконкой или логотипом (файл, курс, подразделение) | Icon (компонент Icon 32 + текст) | Слева |
| Статус | Badge · Default / Info / Success / Warning / Error | Бейдж на всю ширину столбца |
| Атрибут-бейдж (тип, роль) | Badge, в открытом экземпляре `size=hug` и ширина Hug | Слева, по содержимому |
| Доля выполнения | Progress · Normal / Success / Warning / Error | Полоса + значение справа |
| Уровень компетенции | Level · 0–4 | Слева |
| Буквенная оценка A–E (одна или две) | Grade | Слева |
| Участники | Avatars (до 3 фото + «+N») | Слева |
| Этап с номером | Step | Слева |
| Действия с записью | Actions — последним столбцом: одно действие — его иконка, 2+ — меню «…» | Справа |
| Выбор строки | Checkbox — первым столбцом, только по запросу | — |
| Переключатель в строке | Toggle | Слева |
| Раскрытие строки | Expand — первым столбцом (после чекбокса) | — |
| Ручная сортировка строк | Drag — первым столбцом | — |
| Заголовок группы строк | Group — на всю ширину | Слева |
| Поиск ничего не нашел | Empty «Ничего не найдено» — на всю ширину | По центру |

Цвет статуса — по словарю `badge.md`, §4; цвет полосы — по `progress-bar.md`. Красный (Danger, Overdue, Negative,
Error) — только просрочка, отклонение, риск.

## 4. Столбцы

- Порядок: чекбокс → шеврон раскрытия / ручка → название → атрибуты → статус → действия.
- Ширина: название тянется (Fill), остальным столбцам задается фиксированная ширина по самому длинному значению.
  Ориентиры: дата 140, число 140, статус от 184 (бейдж 160 + отступы), прогресс 200, сотрудник 240, действия 52 (одна иконка или «…»),
  чекбокс 40, шеврон 52, ручка 40.
- Все ячейки столбца — одной ширины и одного `Type`; заголовок столбца — той же ширины, с тем же `Align`.
- Крайние столбцы — край содержимого совпадает с полями виджета 24. В Figma таблица стоит внутри полей виджета, у
  первой ячейки строки выключен `Padding left`, у последней — `Padding right`. В верстке `.q-table-wrap` — на всю
  ширину виджета, у крайних ячеек отступ 24 (`assets/table.css`).
- Числа — справа, `tabular-nums`; заголовок числового столбца тоже справа.
- **Бейджи статуса растянуты на всю ширину столбца**, текст по центру — все бейджи столбца одной ширины. Длинный
  статус не обрезается: расширяют столбец целиком.
- Прогресс в ячейке — размер S (`progress-bar.md`): полоса от 48 + значение справа, без подписи; полосы столбца одной
  ширины.
- Аватар в таблице — один размер 32 (Person, Avatars); плитка Icon — тоже 32.

## 5. Строки и состояния

| Состояние | Как | Свойство Figma |
|---|---|---|
| Default | Белый фон, линия снизу `--q-content-border-secondary` | — |
| Hover | Фон `--q-table-hover-tr` у всей строки + название `--q-primary-500` | `Hover` у всех ячеек строки |
| Selected | Фон `--q-table-select` у всей строки, чекбокс отмечен | `Selected` у всех ячеек строки |
| Группа | Высота 40, фон `--q-content-background-disabled`, название 14/20 + пояснение | `Type=Group` |
| Пусто | «Ничего не найдено» по центру | `Type=Empty` |

- **Клик по строке открывает запись.** Кнопок «Открыть», «Просмотр», «Подробнее», «глаз» в строке нет.
- Клики по чекбоксу, шеврону, кнопкам действий и ссылкам внутри строки строку не открывают.
- Раскрывается строка только шевроном; если у строки своей страницы нет — раскрывает клик по всей строке.
- Строка с редактируемыми контролами целиком не кликается: переход — по названию.
- Высоту строки задает самая высокая ячейка; остальные тянутся по высоте и выравнивают содержимое по центру.

## 6. Заголовки и тексты

- Заголовок столбца — существительное, sentence case: «Срок», «Статус», «Ответственный». Единица — через запятую:
  «Сумма, ₽».
- Сортировка — у каждого текстового столбца; у чекбокса, шеврона, ручки и действий — `Type=Empty`.
- Название в ячейке — одна строка с «…», полный текст — в `title`. Вторая строка — подпись 12/16 серым, вплотную к названию (отступ 0).
- Даты — `ДД.ММ.ГГГГ`, суммы — `52 000 ₽`, пустое значение — «—» серым.

## 7. Плотность и отступы

- Ячейка тела 16 · 12, заголовок высотой 40 с отступами 0 · 12. Одна плотность на все таблицы, компактных таблиц нет.
- Без вертикальных линий, зебры, рамки и заливки шапки.
- Таблица стоит прямо в виджете; ритм — по `SKILL.md`, «Ритм виджета» (таблица прямо в виджете — исключение:
  от заголовка виджета до текста `th` 16 + отступ `th`).

## 8. Запреты

**Нельзя:**

1. Ставить кнопку «Открыть», «Просмотр», «глаз» — строка кликается.
2. Раскрывать строку кликом по ней, если у строки есть своя страница, — только шевроном.
3. Ставить чекбоксы без запроса на массовые действия.
4. Смешивать в одном столбце разные `Type`, ширины бейджей или размеры аватаров.
5. Делать вертикальные линии, зебру, рамку таблицы, заливку шапки.
6. Обрезать статус в бейдже или сокращать заголовок столбца ради ширины.
7. Красить в красный что-то кроме просрочки, отклонения, риска.
8. Ставить действия не последним столбцом или выкладывать 2+ действия отдельными иконками — их собирают в меню «…».
9. Менять плотность ячеек или отступы от таблицы к таблице.
10. Собирать ячейку из фигур, если нужный `Type` есть в `Table / Cell`.

## 9. Проверка

- [ ] Ячейки выбраны по §3; один `Type` и одна ширина на столбец.
- [ ] Название тянется; край крайних столбцов совпадает с полями виджета 24.
- [ ] Сортировка у текстовых столбцов; заголовки — существительные.
- [ ] Бейджи статуса на всю ширину столбца, текст целиком; прогресс — размер S.
- [ ] Клик по строке открывает запись; раскрытие — шевроном слева; действия — последним столбцом.
- [ ] Hover и Selected включены у всех ячеек строки, а не у одной.
- [ ] Пустой результат — `Type=Empty` «Ничего не найдено».
- [ ] Цвета — токены `--q-table-*`, `--q-badge-*`, `--q-*`; плотность 16 · 12.

## 10. Особенности Q.HCM

- Таблицы в «Управлении персоналом» (роль 2, Смирнова) — со статусом и прогрессом по каждому сотруднику; чекбоксы,
  «Напомнить» и выгрузка — только у HR.
- В «Моем кабинете» (роль 1, Павел Иванов) таблицы без чекбоксов и без кадровых действий.
- Уровень компетенции — шкала Начальный · Базовый · Уверенный · Экспертный (`Type=Level`, 1–4), не шкала грейдов.
- Буквенная оценка — `Type=Grade`, две буквы «самооценка / руководитель».
- Данные — из `hcm-demo-legend`: цифры в таблице совпадают с шапкой объекта и виджетами.

| Где · роль | Столбцы и ячейки |
|---|---|
