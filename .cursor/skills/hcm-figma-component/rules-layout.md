## Строительные блоки

**Шапка** (`Шапка`, вертикальный, gap 16): надзаголовок → заголовок (русское название компонента) → лид (что компонент делает и какие соседние компоненты его НЕ заменяют) → `Мета` (горизонтальный, gap 24: «Figma: <Имя> (<id набора>)», «Код: <классы и компоненты>», «Обновлено ДД.ММ.ГГГГ») → разделитель `Divider` 1 px `color/border/default`.

**Панель примера** (`Пример`): вертикальный, padding 32, gap 16, радиус 16, фон `color/background/page`. Внутри — `Экран` (горизонтальный, gap 16) с карточками виджетов: вертикальный, padding 20 / 24, gap 16, радиус 12, фон `color/background/surface`, заголовок виджета SemiBold 16/22. Под экраном — подпись 12/16 `color/text/muted`.

**Плитка** (типы, содержимое, состояния): вертикальный фрейм с именем варианта, gap 16:
- `Пример` — padding 28 / 24 (у состояний 24 / 16), gap 12, радиус 12, фон `color/background/surface`, рамка 1 px `color/border/default`, внутри экземпляры компонента (FILL);
- `Group` — gap 4: название 14/20, описание 14/18, служебная строка «Figma: …» 14/18 `color/text/muted`.

Плитки одной строки — в горизонтальном фрейме, gap 16, каждая FILL. Три плитки в ряд — типы и содержимое, по числу состояний — состояния.

**Таблица** (`Таблица`, вертикальный, gap 0):
- `Шапка таблицы` — горизонтальный, gap 24, padding снизу 10, нижняя граница 1 px `color/border/default`, тексты SemiBold 12/16 `color/text/muted`;
- `Строка` — горизонтальный, gap 24, padding 12 сверху и снизу, нижняя граница 1 px `color/border/default`; первая колонка SemiBold 14/20, остальные Regular 14/18; последняя колонка FILL, первые — FIXED.

**Нумерованный список** (`Список`, вертикальный, gap 8, ширина 880): `Пункт` — горизонтальный, gap 12: номер «1.» FIXED + текст FILL.

**Серая плашка правил** (`Правила`): вертикальный, padding 16 / 20, gap 8, радиус 12, фон `color/background/muted`, пункты «•  …» 14/18.

**Блок запретов** (`Запреты`): вертикальный, padding 20 / 24, gap 10, радиус 12, фон `color/background/error-subtle`. Строка `Запрет N` — горизонтальный: номер «N.» SemiBold 14/20 `color/text/error` FIXED + текст 14/18 FILL.

**Пара «Можно / Нельзя»** (`Пара`, горизонтальный, gap 32, две колонки FILL):
- колонка `Можно` / `Нельзя` — вертикальный, gap 0;
- `Пример` — padding 24, фон `color/background/page`, внутри `Виджет` (padding 16 / 20, gap 8, радиус 12, фон `color/background/surface`) с экземплярами;

- `Подпись` — padding сверху 12, gap 4: «Можно» / «Нельзя» 14/20 + объяснение 14/18.

Если в примере элементы стоят в ряд (поле и кнопка), `Виджет` горизонтальный, а кнопка HUG по ширине.

## Проверка верстки

- Все блоки на auto layout, ширины FILL, ничего не позиционировано абсолютно.
- Лиды ровно 880 в ширину, остальной текст — FILL.
- Плитки одной строки одной ширины; разница высот только из-за содержимого.
- Пары «Можно / Нельзя» стоят рядом, маркеры на одной высоте.
- В документе используются экземпляры собираемого компонента, а не его нарисованные копии.
