# Стартовый промт

Подставь компонент и ссылку на страницу и отправь агенту.

```
Собери в Figma компонент <Название> для дизайн-системы Q.HCM.
Страница: <ссылка на страницу в DS-Q.HCM>
Базовая библиотека для сверки состояний: <ссылка, например https://primeng.dev/...>

Прочитай и выполни скилл .cursor/skills/hcm-figma-component/SKILL.md и его файл rules-layout.md. Перед вызовами use_figma прочитай скилл figma-use.

Что нужно на выходе:
1. Набор вариантов: все типы × наполнение × состояния, у каждого варианта имя «Свойство=Значение». Все цвета, размеры, отступы, радиусы и тексты — только на переменных и стилях библиотеки Q.HCM Tokens.
2. Панель вариантов слева: матрица с подписями строк и столбцов и свойства экземпляра.
3. Документ «<Имя> · Правила использования» справа: те же разделы, порядок и верстка, что у эталона Input (страница Input, фрейм 394:3934).

Как работать:
- Сначала изучи эталон Input в Figma (скриншот и структура), прототип в коде (src/styles, src/app/shared/ui, src/app/widgets, public/legacy/index.html), AGENTS.md, скилл minimalism-hcm-ds и правила цвета в Q.HCM Tokens.
- До сборки письменно разбери продуктовую логику: какую задачу решает компонент, где стоит на экранах, какие типы нужны и как выбрать тип, какие состояния видит пользователь, что может пойти не так, что запрещено.
- Решения принимай по источникам в порядке из скилла. Где расходишься с прототипом — не прячь, вынеси в ответ на подтверждение.
- Правила — готовая спецификация: без истории правок и ссылок на наш диалог. Русский язык, «е» вместо «ё», кавычки «ёлочки».
- Тексты внутри компонента — только нейтральные английские заглушки: Title, Subtitle, Name, Position. ФИО, должности и названия продукта в компонент не писать. Так компонент остается нейтральным, как в Material и Human Interface.
- Высота строки кратна 4. Однострочный пункт — 36 px, даже если межстрочный интервал стиля дает 34.
- Иконки бери из библиотеки Q.Icons. Готовые компоненты файла (Avatar и другие) вкладывай экземплярами, не рисуй заново.
- Цвета, отступы, радиусы и стили текста — только из Q.HCM Tokens. Токены Q.Palette Minimalism запрещены.
- Проверяй каждый шаг скриншотом и пройди чек-лист из скилла.
- Код проекта не меняй.

В ответе: что собрано (первым предложением), таблица «прототип / компонент» по размерам и состояниям, список решений, которые мне нужно подтвердить.
```
