# Q.HCM — навыки для макетов

Пакет для коллег, которые собирают экраны Q.HCM в своем инструменте. Здесь правила, дизайн-система, легенда демо, цветовые токены и шрифты. Верстки на Angular в пакете нет.

Снимок 10.11.2026. Дизайн-система — пакет от 01.11.2026. Легенда сверена с прототипом на 01.10.2026 и с решениями заказчика от 07.10.2026 и 29.10.2026. Сегодня в демо — 30.09.2026.

## Что внутри

| Папка | Зачем |
|---|---|
| `q-hcm-pravila/` | Как собирать экран: фильтры, таблицы, кнопки, вкладки, прогресс. Рядом `cvetovye-tokeny.md` и `shrifty.md` |
| `minimalism-hcm-ds/` | Дизайн-система: каркас, компоненты, блоки экрана, спецификации Figma |
| `hcm-demo-legend/` | Люди, роли, цифры и сюжет «Меридиан Банк» |

## Как подключить агенту

Скопируйте три папки в `.cursor/skills/` проекта. Имена папок сохраняют: по ним агент находит скиллы.

На макет агент читает `q-hcm-pravila`, затем нужные файлы дизайн-системы. Легенду открывает, когда на экране появляются люди и цифры. Спецификации из `minimalism-hcm-ds/figma/` — когда собирается сам компонент в Figma.

В макете подписывают имя токена (`--q-primary-500`, `--q-font-ui-headline-2`). Hex и кегль из справочников нужны, чтобы завести переменные, и в макет вместо имени не подставляются.

Если пример в компоненте расходится с легендой, права легенда.
